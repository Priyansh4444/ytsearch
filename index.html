ytsearch

Find the moment a creator said it, across every indexed video.

Search what YouTube creators actually said

ytsearch searches the public captions of more than 70 YouTube creators, about 50,000 videos in all, and takes you to the exact moment a phrase was spoken. Use it to check a quote, find an explanation you half remember, or see everything a channel has said about a topic. Start with @ to pick a creator, or request one that is missing.

It is free, has no accounts, and runs on an open-source Rust search index. Developers and AI agents can call the same search through a public JSON API that needs no key.
