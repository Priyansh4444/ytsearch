# Contact

ytsearch is run by one person, so public issues are the most reliable way to reach the project: they are read regularly, and the answer helps the next person with the same question.

## Bugs, wrong results and feature ideas

Open an issue on [GitHub](https://github.com/Priyansh4444/ytsearch/issues). For a search problem, include the link to the search, what you expected to find and, if you know it, the video and timestamp.

## Adding a creator

Type the channel's handle, such as `@creator`, in the search box on the home page and confirm the request. Requests are reviewed before indexing starts.

## Creators and removal requests

If you run a channel and want it removed or corrected, open a GitHub issue naming the channel. ytsearch indexes public captions only and always links back to YouTube, where the original video and its view count stay.

## Privacy questions

The [privacy page](https://search.pronsh.dev/privacy) lists what is logged and for how long. Ask anything it does not answer through the same GitHub issues.
