# ytsearch

Search inside YouTube transcripts and jump straight to the moment that matters.

ytsearch searches the public captions of more than 70 YouTube creators, about 50,000 videos in all, and links each result to its exact timestamp. It is free, needs no account, and has a public JSON API.

## Search

Open `https://search.pronsh.dev/?q=YOUR+WORDS`, or call the API:

```sh
curl 'https://search.pronsh.dev/api/v1/search?q=server+actions&per_page=3'
```
